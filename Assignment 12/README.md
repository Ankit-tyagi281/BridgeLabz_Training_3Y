# Assignment 12 — Core JavaScript

This folder contains ten separate JavaScript solutions. Each file includes comments describing the logic.

## Files
- `Q1.js` — Scope Conflict Resolver
- `Q2.js` — String Manipulation Report
- `Q3.js` — Math Utility Dashboard
- `Q4.js` — Array Performance Analyzer
- `Q5.js` — Boolean Logic Access System
- `Q6.js` — Event-Based Counter Simulation
- `Q7.js` — Customer Feedback Processor
- `Q8.js` — Dynamic Discount Evaluator
- `Q9.js` — Odd–Even Number Analyzer
- `Q10.js` — Departmental Employee Evaluator

## Run with Node.js
From the repository root, run a file using:

```bash
node "Assignment 12/Q1.js"
```

Replace `Q1.js` with the file you want to run. The examples use only built-in JavaScript features and no external libraries. Change sample values in each file to test other cases.
