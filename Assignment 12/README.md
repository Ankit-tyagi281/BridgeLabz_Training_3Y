# Assignment 12 — JavaScript Data, Errors, Scope & Hoisting

Ten separate JavaScript files, using built-in language features, strict mode where applicable, comments, and console output.

## Questions
- Q1 — Dynamic data conversion and numeric validation
- Q2 — Employee bonus calculator, conversion, and try/catch
- Q3 — Transaction validation and categorized errors
- Q4 — Strict-mode undeclared-variable debugging
- Q5 — Hoisting, temporal dead zone, and arrow functions
- Q6 — Pyramid pattern and configurable row count
- Q7 — Switch-based calculator and custom errors
- Q8 — Strict-mode restrictions and corrected ES6 code
- Q9 — JSON audit and age filtering
- Q10 — Nested hoisting, shadowing, arrow functions, and call stack

## Run
Run an individual question from this folder with Node.js, for example:

```bash
node Q1.js
node Q2.js
```

To set a custom pyramid height (default 5, maximum 50):

```bash
node Q6.js 7
```

## Debugging
In VS Code, click beside a line number to set a breakpoint, choose **Run and Debug**, use **Step Over** to follow execution, **Watch** to inspect variables, and **Call Stack** to inspect active function calls. See comments in each file for suggested watch variables and expected hoisting behavior.
