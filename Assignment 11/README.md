# Assignment 11 — Core JavaScript

This folder contains ten separate JavaScript programs for the assignment.

## Files
- `Q1.js` — Personalized Login Greeting
- `Q2.js` — Multi-Type Data Summary
- `Q3.js` — Monthly Expense Tracker
- `Q4.js` — Academic Performance Evaluator
- `Q5.js` — Weather Activity Planner
- `Q6.js` — Progressive Discount System
- `Q7.js` — Smart Guessing Game
- `Q8.js` — Employee Salary Projection
- `Q9.js` — Random Math Quiz Generator
- `Q10.js` — Citizen Eligibility Validator

## Run
Use Node.js from the repository root, for example:

```bash
node "Assignment 11/Q1.js"
```

Edit the sample values near the top of each file to test different cases. These examples use core JavaScript only.
