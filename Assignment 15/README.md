# Assignment 15 — JavaScript Callbacks, Prototypes, Closures, and Classes

This assignment uses core JavaScript (ES6+) with a separate file for each question.

## Questions
- **Q1.js** — Callback flow
- **Q2.js** — Callback operations on arrays
- **Q3.js** — Arrow function `this` vs. normal function `this`
- **Q4.js** — Constructor functions and shared prototype methods
- **Q5.js** — Prototype inheritance: Person → Student
- **Q6.js** — Prototype chain: Person → Faculty → Professor
- **Q7.js** — Closures and multiplier functions
- **Q8.js** — Custom array `myMap()` method
- **Q9.js** — Prototype inheritance compared with ES6 classes

## Run with Node.js
From the repository root, run any question separately:

```bash
node "Assignment 15/Q1.js"
node "Assignment 15/Q2.js"
node "Assignment 15/Q3.js"
node "Assignment 15/Q4.js"
node "Assignment 15/Q5.js"
node "Assignment 15/Q6.js"
node "Assignment 15/Q7.js"
node "Assignment 15/Q8.js"
node "Assignment 15/Q9.js"
```

All examples use built-in JavaScript only; no frameworks are required.
